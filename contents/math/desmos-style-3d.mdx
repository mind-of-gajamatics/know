# Desmos-Style 3D Graph Controls 🎮

Our 3D graphing component now features professional controls inspired by Desmos! Experience smooth interactions with momentum, multiple control modes, and a beautiful grid floor.

## 🎯 Control Features

### Mouse Controls
- **Left-Click + Drag** - Orbit/rotate around the center
- **Right-Click + Drag** - Pan the view laterally
- **Shift + Drag** - Alternative pan control
- **Scroll Wheel** - Smooth zoom in/out
- **Momentum** - Throw the graph with a flick!

### Touch Controls
- **One Finger Drag** - Rotate the graph
- **Two Finger Drag** - Pan the view
- **Pinch** - Zoom in and out

### Quick View Buttons
- **🏠 Home** - Reset to default view
- **▶️ Auto** - Auto-rotate for presentations
- **🟩 Grid** - Toggle grid floor
- **X/Y/Z** - Jump to axis-aligned views
