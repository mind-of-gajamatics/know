## Mexican Hat (Sombrero)

The classic: **z = sin(√(x² + y²)) / √(x² + y²)**

<MathGraph3D
  title="Mexican Hat"
  func={(x, y) => {
    const r = Math.sqrt(x * x + y * y)
    return r === 0 ? 1 : Math.sin(r) / r
  }}
  xMin={-10}
  xMax={10}
  yMin={-10}
  yMax={10}
  color="#ec4899"
  gridSize={30}
/>

## Features

- 🔄 **Rotate** - Drag to rotate the view
- 🔍 **Zoom** - Scroll to zoom in/out
- 📐 **Axes** - Color-coded X (red), Y (green), Z (blue)
- 🎨 **Wireframe** - Beautiful mesh rendering
- 📱 **Touch** - Works on mobile devices

## Usage

### Single Surface
\`\`\`jsx
<MathGraph3D
  title="My 3D Function"
  func={(x, y) => x * x + y * y}
  xMin={-3}
  xMax={3}
  yMin={-3}
  yMax={3}
  color="#3b82f6"
/>
\`\`\`

### Multiple Surfaces
\`\`\`jsx
<MathGraph3D
  title="Compare Surfaces"
  surfaces={[
    { func: (x, y) => x * x, color: '#3b82f6', label: 'z = x²' },
    { func: (x, y) => y * y, color: '#ec4899', label: 'z = y²' }
  ]}
/>
\`\`\`
